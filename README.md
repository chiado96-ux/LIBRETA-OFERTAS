# Libreta de Ofertas

Web app para iPad (funciona sin internet) que sustituye la libreta de ofertas de residuos industriales.

**Instalación en iPad:** abrir https://chiado96-ux.github.io/libreta-ofertas/ en Safari → Compartir → "Añadir a pantalla de inicio".

Los datos se guardan únicamente en el dispositivo. Copias de seguridad desde el menú ⋮ de la app.
